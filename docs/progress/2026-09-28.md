## Per-request image size and aspect-ratio control

- Added a compact native image-size picker beside the checked-by-default image
  generation toggle. It offers `Auto`, model-established aspect ratios with
  representative pixel sizes, and a custom width/height editor.
- The request contract is explicit: conversation dimensions or ratios override
  the picker, the picker overrides the administrator default, and omission
  keeps the administrator default. Unsupported dimensions are rejected before
  relay and are never silently resized, retried, or replaced.
- Native chat draft state now preserves `imageGenerationSize` across draft
  restoration and resets it to `auto` for a new draft. Switching models keeps
  an explicit choice and marks it unsupported until the selected model supports
  it; it does not silently change the user's selection.
- The bridge recognizes exact pixel forms such as `1980x1200` and ratio forms
  such as `4:3`, including full-width separators. Fixed-size models expose
  only their known sizes; exact custom dimensions are validated only for the
  established `gpt-image-2` model. The selected size is applied after admin
  image parameters so it cannot be overwritten by the global default.
