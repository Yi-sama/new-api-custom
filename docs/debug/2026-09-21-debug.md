## 新注册账号登录 500

- 精确错误：`POST /api/user/login` 返回 500，服务端记录 `auth session internal error ... user authentication state update is pending`。账号密码校验已通过，失败发生在 Session 签发读取用户授权状态时。
- 证据链：用户“宇”为数据库 `id=15, auth_version=1, last_login_at=0`；Redis `auth:user:version:15=2` 且无过期时间；源码 `model/user_cache.go` 在 Redis floor 高于数据库版本时返回 `ErrUserAuthCachePending`。同日用户 `13`、`14` 具有相同不一致，历史日志仍保存旧 `user_id=15/16`，Redis 也保留 ID `16` 的版本键。
- 根因：数据库恢复后的序列按现存用户最大 ID 修复，未考虑历史引用和 Redis 永久身份状态，导致新注册复用旧身份 ID。注册后的侧栏初始化会尝试刷新缓存，但其错误未影响注册成功响应，因此形成“注册成功、首次登录 500”。
- 修复：完整备份后，将用户 `13–15` 数据库版本提升到 `2`，把序列设为 `16`，保留全部 Redis floor。全用户扫描无剩余版本不一致，服务未重启且保持 healthy。
- 工具过程：数次远端只读命令因 PowerShell/Bash 嵌套引号、CRLF 或本地 JavaScript 编码 API 缺失而在查询前或 SSH 前失败；均未修改远端。最终使用 PowerShell UTF-8 Base64 原样传输脚本，备份、事务和验证成功。
