# 2026-09-24

## Missing Image Studio tab on localhost:3000

- Cause: the rc28 integration had only been written to the sibling checkout;
  the actual port-3000 binary and source were from this `new-api` checkout.
- Resolution: moved the integration to the active checkout, rebuilt and
  restarted its local process against the original database. Browser AX
  confirmed the top `Image Studio` link at `http://localhost:3000/`.
- A combined PowerShell launch/check/stop command was rejected by tool policy
  before execution. Separate launch, HTTP checks, and stop calls succeeded.
  An in-app browser click on the login modal's Cancel button failed to resolve
  the shadow-root target; its timer then navigated to sign-in. Returning to
  the homepage succeeded. Neither tool error changed project data.
- Open WebUI remains unconfigured; the tab currently uses the existing
  image Playground fallback, not a running Open WebUI instance.
- The first public-header screenshot at roughly 800px showed Chinese nav
  labels wrapping one character per line. Moving the full row to `xl`,
  retaining a compact Image Studio link, and widening the scrolled
  container resolved it in browser screenshots.
- A parallel Vitest run hit Windows/V8 memory exhaustion and returned no
  test results. Re-running the focused test with `--maxWorkers=1
  --fileParallelism=false` passed. The browser's old webview timed out
  attaching after restart; a fresh tab in the same browser loaded normally.
